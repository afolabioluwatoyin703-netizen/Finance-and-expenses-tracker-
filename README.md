# Finance-and-expenses-tracker-
Finance and expenses tracker is a webpage that helps track your money, budget and expenses 




MoneyTrack — Personal Finance & Expense Tracker

Project description

MoneyTrack is a simple website that helps users record income and expenses, view their balance, set a monthly budget, and see how much they spend in different categories.


Features


Dashboard showing income, expenses, balance, and budget remaining.

Navigation links to Dashboard, Transactions, Budget, and Categories.

Add income or expense transactions.

View and delete transactions.

Clear all transactions after confirmation.

Set a monthly budget and view spending progress.

View expenses grouped by category.

Save transactions and budget in the browser using local storage.

Responsive layout for phones and computers.


Technologies used


HTML

CSS

JavaScript

Browser local storage


How to run it


Download the project files.

Keep index.html, style.css, and script.js in the same folder.

Open index.html in a web browser.

Add transactions and set your budget.
